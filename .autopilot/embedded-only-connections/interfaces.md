# Interfaces — что изменилось для следующих тикетов

## RDP-контракт (shared + preload)

- `RdpLaunchResult` больше не содержит `mode: 'window'` — только
  `{ ok: true, sessionId }` или `{ ok: false, error }`. Убран `launchWindowed`.
- `rdp:launch` всегда идёт через embedded-путь: `mstsc.exe` запускается
  как дочерний процесс, его HWND прикрепляется к HWND панели вкладки через
  `SetParent`; до подтверждённого `SetParent` окно скрыто и не считается
  подключённым.

## RDP-менеджер (main)

- Режимы профиля `screenMode=fullscreen` и `multiMonitor=true` нормализуются
  на фактическом запуске в embedded-совместимый `.rdp`
  (`screen mode id:i:2`, `use multimon:i:0`, валидное разрешение);
  настройка профиля при этом сохраняется.
- `findSecurityWarning` / `rejectSecurityWarning` — распознавание и закрытие
  системного диалога сертификата по классу `#32770` и тексту содержимого
  (не по заголовку). При ручном режиме сертификата диалог скрывается,
  а решение показывается в баннере вкладки (`.rdp-cert-banner`).
- Сторож повторяет встраивание, пока HWND панели не готов; при ручном
  подтверждении сертификата баннер не повторяется и сессия не теряется.

## IPC / renderer

- `rdp:certificate` — событие о pending-сертификате; состояние
  `certificatePending` живёт в сторе вкладки, успешный ответ `rdp:launch`
  больше не сбрасывает уже показанный баннер (исправлена гонка).
- Полноэкранный режим RDP — CSS-режим вкладки внутри рабочей области
  (`.rdp-pane--fullscreen`), кнопка выхода; отдельного окна ОС нет.

## Защита окна (main)

- `setWindowOpenHandler` запрещает popup-окна; `will-navigate` блокирует
  навигацию, кроме текущего renderer-origin и точного локального `index.html`.

## Смоук

- Смоук RDP-разрешения проверяет «полный экран остаётся вкладкой»,
  а не старый fallback `mode=window`; смоук сертификата — авто-подтверждение
  без видимого предупреждения и ручное решение в баннере вкладки.
