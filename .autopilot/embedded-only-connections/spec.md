# Спецификация

## Решение

Remote Hub использует единое рабочее пространство: дерево профилей слева, одна строка вкладок сверху и содержимое активной сессии внутри renderer. Это соответствует выбранным паттернам:

- **Remote Desktop Manager**: единый workspace с embedded/tabbed-представлением для RDP, VNC, SSH и других протоколов.
- **mRemoteNG**: multi-protocol connection manager с вкладками в одном окне и группами профилей.
- **Royal TS**: connection tabs, встроенные RDP/VNC/SSH/SFTP и централизованные credential objects.
- **Termius**: terminal tabs, встроенный SFTP и быстрый переход между подключениями.

## Поведение по протоколам

- SSH/Telnet продолжают использовать xterm-панели во вкладках.
- VNC продолжает использовать noVNC canvas во вкладке и локальный WebSocket-мост без внешнего VNC-клиента.
- SFTP продолжает использовать встроенную файловую панель во вкладке; нативные диалоги выбора/сохранения файлов не являются окнами remote-сессии.
- RDP запускает системный `mstsc.exe` только как дочерний Win32-клиент, который сразу прикрепляется к HWND главного окна Electron. Менеджер больше не имеет режима `window` и не возвращает top-level RDP-сеанс.

## RDP fullscreen и multi-monitor

Режимы профиля не могут обходить правило embedded-only:

- для `screenMode=fullscreen` менеджер генерирует embedded-совместимый оконный `.rdp` (`screen mode id:i:2`) с сохранённым разрешением, затем встраивает его в сцену RDP-вкладки;
- для `multiMonitor=true` менеджер отключает `use multimon` только на фактическом embedded-запуске и использует одну сцену вкладки, чтобы не создавать несколько внешних окон; настройка профиля сохраняется;
- кнопка полноэкранного режима переключает размер/состояние RDP-вкладки внутри главного окна и переподключает профиль без внешнего окна;
- UI не содержит сообщения «открыто отдельное окно» и не предлагает внешний fallback.

## Защита окна приложения

`BrowserWindow` запрещает popup-окна через `setWindowOpenHandler` и блокирует навигацию, кроме текущего renderer-origin и точного локального `index.html`. Открытие репозитория из меню остаётся отдельным штатным действием справки, но remote-сессии не используют shell или external URL.

## Ошибки и жизненный цикл

Окно mstsc прикрепляется, скрывается при смене вкладки/модальном overlay и закрывается вместе с вкладкой или приложением. До подтверждённого `SetParent` найденный HWND скрыт и не считается встроенным; ошибка поиска/встраивания дочернего RDP-окна приходит в overlay вкладки. Предупреждение сертификата либо автоматически подтверждается, либо скрывается и отображается в баннере вкладки. Юнит-тесты проверяют fullscreen/multi-monitor, порядок hide → embed, ручное принятие/отмену сертификата и отсутствие `mode=window`; smoke-проверки сохраняют покрытие SSH/Telnet, VNC, SFTP и RDP.
