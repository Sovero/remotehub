# Манифест

| ID | Требование | Статус |
|---|---|---|
| R01 | SSH и Telnet открываются только во вкладках главного окна, без отдельного окна клиента. | in-spec |
| R02 | VNC открывается только во вкладке главного окна, без отдельного окна клиента. | in-spec |
| R03 | SFTP открывается только во вкладке главного окна, без отдельного окна клиента. | in-spec |
| R04 | Любой RDP-профиль, включая полноэкранный и мультимониторный, открывается только внутри вкладки главного окна; отдельный top-level fallback запрещён. | in-spec |
| R05 | Полноэкранный режим RDP остаётся управляемым из приложения и не переводит сессию во внешнее окно. | in-spec |
| R06 | Внешняя навигация или создание popup-окон из окна приложения блокируются; штатные действия приложения не должны запускать remote-клиенты снаружи. | in-spec |
| R07 | Решение следует проверенным паттернам табовой работы Remote Desktop Manager, mRemoteNG, Royal TS и Termius; выбранные паттерны фиксируются в спецификации. | in-spec |
| R08 | Покрыть правило тестами и собрать приложение. | in-spec |
