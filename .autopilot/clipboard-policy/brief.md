# Бриф: общая политика буфера обмена для SSH, RDP и VNC

## Проблема

Политика «разрешить / спрашивать / запретить» с пределом размера появилась только
для OSC 52 в SSH-сессиях. RDP (`remoteClipboardChangedCallback`) и VNC (событие
`clipboard` от noVNC) по-прежнему писали текст с удалённой стороны в буфер Windows
молча и без ограничения размера: любой сервер мог подменить буфер пользователя,
в том числе мегабайтами данных.

## Чего хочет пользователь

Одна настройка на все протоколы: разрешить, спрашивать или запретить запись в
буфер из удалённой сессии, с тем же пределом размера. Общий диалог подтверждения
для SSH, RDP и VNC.

## Границы

- Касается только направления «удалённая сторона → локальный буфер».
  Вставка из локального буфера в сессию и копирование выделения мышью не меняются.
- Чтение буфера сервером (OSC 52 `c;?`) по-прежнему не поддерживается.
- Предел и политика — общие для приложения, без настройки на отдельный хост.
