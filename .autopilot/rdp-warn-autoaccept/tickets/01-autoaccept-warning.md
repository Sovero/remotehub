# T01: Авто-подтверждение предупреждения безопасности mstsc

**Требования:** R01, R01.1, R02i, A01

**Суть:** mstsc в новых Windows не запоминает принятый сертификат и показывает
предупреждение безопасности при каждом подключении. Приложение гасит его автоматически:
движок находит диалог по заголовку и кликает «Подключить» (BM_CLICK), окно диалога
исключается из кандидатов на встраивание, сторож повторяет подтверждение на каждый тик.

**Файлы:**
- `src/main/rdp/win32-engine.ts` — `confirmSecurityWarning(pid)`, `windowText`,
  `isWarningDialog`, пропуск диалога в `findWindowByPid`
- `src/main/rdp/embed.ts` — метод `confirmSecurityWarning` в интерфейсе и noop-движке
- `src/main/rdp/manager.ts` — вызов подтверждения в `tick()`
- `src/main/index.ts` — смоук против живого порта (RH_RDP_PORT), проверка отсутствия
  предупреждений после встраивания
- `tests/rdp-embed.test.ts` — фейк-движок + тест «сторож гасит предупреждение»

**Приёмка:** смоук `RH_SMOKE_RDP_EMBED=1 RH_RDP_PORT=3389` — «окно встроено, предупреждение
безопасности погашено»; 99/99 тестов; typecheck чист.
