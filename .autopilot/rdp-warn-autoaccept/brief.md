# Бриф: RDP не должен спрашивать при каждом подключении

> «при каждом подключении спрашивает что подключить в rdp сессию - нужно сохранять настройки, а не спрашивать одно и тоже каждый раз»
> «вот пример приложения где rdp открывается внутри "C:\ProgramData\Microsoft\Windows\Start Menu\Programs\Remote Desktop Manager\Remote Desktop Manager (RDM).lnk"»

Пользователь подключился к RDP через приложение — и при каждом запуске mstsc показывает
диалог, который он воспринимает как «что подключить». Нужно, чтобы вопрос не задавался
каждый раз, а RDP открывался внутри приложения, как в Remote Desktop Manager.
