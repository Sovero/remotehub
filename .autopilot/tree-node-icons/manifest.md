# Манифест: иконки узлов дерева профилей

| ID | Требование | Статус |
|----|-----------|--------|
| R01 | ProtocolIcon умеет рисовать иконку группы (папку) | in-spec |
| R02 | Папка группы различает развёрнутый (открытая папка) и свёрнутый (закрытая) узел | in-spec |
| R03 | Шеврон узла и папка в дереве — SVG (не текстовые глифы ▸/▣) | in-spec |
| R04 | Контраст новых иконок проверяется смоуком (темы × акценты) | in-spec |
| A01 | Смоук иконок проверяет переключение развёрнутости: шеврон поворачивается, папка меняется открытая↔закрытая | in-spec |
| A02 | Цвет папки задаётся темой (var(--warn)), как у прежнего глифа | in-spec |
