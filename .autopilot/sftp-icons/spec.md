# Спека: иконки SFTP вместо текстовых глифов

## Требования

### R01 — иконки файла/папки
- В набор Icon добавлена иконка `file` (документ с загнутым углом).
- Строка каталога: `<Icon name={e.isDirectory ? 'folder' : 'file'} size={12} />` вместо глифов `▸`/`▢`.
- Цвета сохранены: папка — `var(--warn)` (`.sftp-ico--dir`), файл — `--text-muted` (`.sftp-ico`).

### R02 — направление передач
- Строка передачи: `<Icon name={o.direction === 'upload' ? 'upload' : 'download'} size={11} />` вместо `↑`/`↓` (обе — и активные, и завершённые).
- Имя файла вынесено в `.sftp-op-file` с ellipsis; `.sftp-op-name` — inline-flex.

### R03 — завершённая передача
- Мета завершённой передачи: `<Icon name="check" size={10} />` вместо `✓`.

### R04 — поведение
- Логика списка/передач не менялась — только рендер иконок и CSS-выравнивание.

## Проверка (A01/A02)

Новый смоук `RH_SMOKE_SFTP` на реальном SFTP-сервере (`ssh2` Server, виртуальная ФС: var/, app.log, config.yml):
1. Открывает SFTP по SSH-хосту через контекстное меню.
2. Ждёт 3 строки в удалённой колонке; проверяет иконки: у папки `.sftp-ico--dir` с folder-иконкой (`d` начинается с `M2.2 4.2`), у файла — file-иконка (`M3.2 2.4`).
3. Двойной клик по файлу → реальное скачивание (в смоуке `RH_SMOKE=1` нативный диалог заменён на temp-путь в `ipc.ts`): строка передачи с download-иконкой (`M8 2.6`).
4. Ждёт завершения: `.sftp-op--done` с иконкой `check` (`M3 8.4`).
5. Результат: `ok:rows=3`.

Смоук проходит в dev и packaged; 107/107 тестов; typecheck чист.
