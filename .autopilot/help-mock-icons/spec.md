# Спецификация

## R01, R02 — SVG-иконки в моках справки

Моки рисуются инлайн-SVG (компонент `Mock`), поэтому иконки встраиваются как `path` с
классами `m-stroke-*` (цвет = переменная темы) через хелпер `IconPath` и карту путей `ICON`,
совпадающую с `Icon.tsx`.

### Замены

| Мок | Было | Стало |
|---|---|---|
| Терминал, кнопки поиска | `↑` / `↓` (текст) | `chevron-up` / `chevron-down` (как в реальной панели поиска) |
| SFTP, список каталога | `▸ папка/`, `▢ файл.txt` (и серверная колонка) | иконки `folder` (янтарная) и `file` (приглушённая), текст справа |
| SFTP, передачи | `↑ загрузка · ↓ скачивание` | иконки `upload` / `download` с подписями |
| VNC, кнопка | `⛶ Полный экран` | иконка `expand` + текст |
| Диагностика, шаги | `↓` между шагами | иконка `arrow-down` |
| Диагностика, финал | `4. Сессия открыта ✓` | текст + иконка `check` |

Тип `d` в `IconPath` расширен до `readonly string[]` (карта `ICON` — `as const`).

## Проверка

Смоук иконок (`RH_SMOKE_ICONS`) дополнен проверкой справки: открывается диалог справки,
последовательно открываются разделы «Терминал», «RDP, VNC и SFTP», «Частые вопросы»;
в каждом есть моки с `path[class*="m-stroke-"]` (≥2) и в тексте нет глифов ▸▢↑↓✓.
