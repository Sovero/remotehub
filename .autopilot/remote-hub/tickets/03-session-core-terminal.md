# 03 — Ядро сессий: SSH и Telnet терминалы, вкладки

**Требования:** R03, R08i, A03, A05
**Blocked by:** 01
**Status:** ready

## Что должно заработать

Открытие SSH- и Telnet-профиля даёт вкладку с настоящим xterm-терминалом: ввод/вывод потоком через IPC, размер следует за окном (fit), авторизация по паролю (диалог внутри вкладки, в т.ч. keyboard-interactive), keep-alive из настроек профиля. Вкладки: несколько сессий сразу, переключение кликом и Ctrl+Tab, закрытие Ctrl+W с подтверждением активной сессии, состояния «подключается/подключена/ошибка/отключена» с оверлеем ошибки и кнопкой «Переподключить». Строка быстрого подключения `user@host[:port]` в шапке с предложением сохранить профиль после успеха. Восстановление вкладок после перезапуска в состоянии «отключено».

## Критерии приёмки

- [ ] SSH-подключение к реальному серверу (или localhost-серверу теста) работает: ввод/вывод, resize
- [ ] Telnet-подключение работает тем же потоком
- [ ] Диалог пароля и keyboard-interactive внутри вкладки, ошибка аутентификации показана и можно повторить
- [ ] Обрыв соединения — оверлей с причиной и «Переподключить»
- [ ] Несколько вкладок, переключение Ctrl+Tab, закрытие Ctrl+W с подтверждением
- [ ] Быстрое подключение `user@host[:port]` открывает сессию; после успеха предлагает сохранить в дерево
- [ ] Вкладки восстанавливаются после перезапуска в состоянии «отключено»
- [ ] Конфиг ssh2/telnet строится из профиля (шов 6); юнит-тесты зелёные; typecheck проходит
