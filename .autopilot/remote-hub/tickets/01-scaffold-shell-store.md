# 01 — Каркас, оболочка окна, хранилище и крипта

**Требования:** R01, R07i
**Blocked by:** —
**Status:** ready

## Что должно заработать

Проект Electron + React + TypeScript поднимается, окно приложения с тёмной темой открывается, в нём виден каркас Termius-подобного интерфейса: левая панель (пока пустая), вкладки сверху (пока пустая), статус-бар снизу. Профили, настройки и учётные данные сохраняются в userData с атомарной записью, бэкапом и версией схемы; пароли шифруются через safeStorage (DPAPI). Окно помнит размер и позицию; повторный запуск не плодит дубли. Первый запуск показывает приветственный экран «нет профилей».
