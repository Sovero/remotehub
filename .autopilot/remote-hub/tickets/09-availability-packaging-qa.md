# 09 — Проверка доступности, упаковка, финальный QA

**Требования:** A01
**Blocked by:** 01, 02
**Status:** ready

## Что должно заработать

Пункт «Проверить доступность» в контекстном меню хоста: TCP-порт (по протоколу) и ICMP ping, результат — во всплывающей подсказке рядом с хостом. Финальная упаковка: `npm run dist` собирает NSIS-установщик; приложение устанавливается, запускается, работает после установки. Финальный QA-проход по всем 61 историям спеки: пустые состояния, ошибки, обрывы, перезапуск.

## Из брифа, дословно

> «С деревом профилей» *(меню хоста)*
> «разработай приложение для Windows» *(установщик)*

## Разделы спеки

История 56; §Контракт IPC (check:port/ping), §Стек (electron-builder), §Вне рамок.

## Критерии приёмки

- [ ] Проверка порта и ping из контекстного меню; результат показан у дерева; недоступный хост — понятный статус
- [ ] `npm run dist` собирает установщик без ошибок; установка и запуск проверены
- [ ] Все юнит-тесты и typecheck зелёные
- [ ] Пройден ручной QA-чекин по историям: первый запуск, пустые состояния, неверный ввод, обрыв сети, перезапуск с восстановлением вкладок
