# 08 — SFTP и туннели

**Требования:** R04 (SFTP), R03.11
**Blocked by:** 03, 04
**Status:** ready

## Что должно заработать

Для SSH-профилей — SFTP-вкладка: две панели (локально слева, удалённо справа), навигация по каталогам, загрузка и скачивание файлов с прогрессом, создание папок, переименование, удаление (с подтверждением), обновление списка. Обрыв передачи: ошибка с пометкой, что частичный файл не целый. Отдельно — порт-форвардинг: диалог «локальный порт → целевой хост:порт», список активных туннелей с остановкой; туннель живёт, пока жива SSH-сессия.

## Критерии приёмки

- [ ] SFTP: листинг, навигация по каталогам, mkdir, rename, delete (с подтверждением) — юнит-тесты на конфиге сессии и обработке ошибок; интеграция — против реального SSH-сервера
- [ ] Загрузка и скачивание с прогрессом; частичный файл при обрыве помечается
- [ ] Туннель: добавление, листинг, остановка; коннект через локальный порт доходит до цели
- [ ] Туннели закрываются вместе с SSH-сессией
- [ ] typecheck проходит
