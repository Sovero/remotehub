# 08 — SFTP и туннели

**Требования:** R04 (SFTP), R03.11
**Blocked by:** 03, 04
**Status:** ready

## Что должно заработать

Для SSH-профилей — SFTP-вкладка: две панели (локально слева, удалённо справа), навигация по каталогам, загрузка и скачивание файлов с прогрессом, создание папок, переименование, удаление (с подтверждением), обновление списка. Обрыв передачи: ошибка с пометкой, что частичный файл не целый. Отдельно — порт-форвардинг: диалог «локальный порт → целевой хост:порт», список активных туннелей с остановкой; туннель живёт, пока жива SSH-сессия.

## Критерии приёмки

- [x] SFTP: листинг, навигация по каталогам, mkdir, rename, delete (с подтверждением) — интеграция против реального SSH-сервера (`tests/sftp-tunnels.test.ts`)
- [x] Загрузка и скачивание с прогрессом; частичный файл при обрыве помечается («файл неполный (N из M)»)
- [x] Туннель: добавление, листинг, остановка; коннект через локальный порт доходит до цели (round-trip против реального ssh2-сервера)
- [x] Туннели закрываются вместе с SSH-сессией (`stopAll`)
- [x] typecheck проходит

## Бонус-фикс

`session:open` теперь принимает `sessionId` рендерера (`SessionOpenRequest.sessionId`): раньше main генерировал свой id, store менял key вкладки, React перемонтировал `TerminalPane` — и непроксированный `setTimeout` в конструкторе xterm `Viewport` падал на `syncScrollArea` после dispose. Краш «Cannot read properties of undefined (reading 'dimensions')» воспроизводился на каждом открытии SSH-сессии; смоук-прогоны подтверждают 0 крашей. Также добавлен стек-капчер ошибок рендерера в `main.tsx` (для QA).

## Смоук
