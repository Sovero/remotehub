# 02 — Дерево профилей

**Требования:** R05, A02, A04
**Blocked by:** 01
**Status:** ready

## Что должно заработать

Левая панель превращается в дерево «группы → хосты» в духе Termius: вложенные группы, хосты в корне или в группе, иконки протоколов, свёрнутые группы. Полный CRUD через диалоги с валидацией, дублирование хоста, контекстное меню (подключить, изменить, дублировать, удалить, SFTP — подключение пока заглушкой), перетаскивание узлов с переносом поддерева, поиск по имени/адресу/тегу, теги хостов и фильтр по тегу. Экспорт/импорт дерева в JSON (без секретов, режимы «слить»/«заменить»). Пустые состояния: нет профилей, пустая группа, пустой результат поиска. Удаление группы — с подтверждением количества хостов внутри.

Истории 28–35, 57, 59; §Решение, §Схема данных (TreeNode); Шов 4.

## Критерии приёмки

- [ ] Группы (вложенные) и хосты создаются/редактируются/удаляются через диалоги; валидация: имя обязательно, адрес обязателен, порт — число
- [ ] Двойной клик по хосту открывает вкладку (пока заглушку «сессия ещё не реализована»)
- [ ] Drag&drop переносит хост/группу в другую группу с сохранением целостности дерева
- [ ] Поиск фильтрует дерево на лету; пустой результат показывает «ничего не найдено»
- [ ] Теги: добавление на хост, фильтр по тегу
- [ ] Экспорт/импорт JSON с режимами «слить» и «заменить»; секретов в экспорте нет
- [ ] Удаление группы спрашивает подтверждение с числом хостов
- [ ] Юнит-тесты на шве 4 (перенос, поиск, валидация, дублирование, импорт) зелёные; typecheck проходит
