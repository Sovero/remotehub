# Спецификация

## R01–R03 — версия по правилам semver

`scripts/bump-version.mjs` — поднимает `version` в package.json:

- строго `MAJOR.MINOR.PATCH` (pre-release и метаданные сборки отклоняются с ошибкой);
- по умолчанию — патч, флаги `--minor` и `--major` (сброс младших разрядов);
- формат файла сохраняется байт-в-байт (заменяется только строка `"version"`).

Вызывается в начале `dist` и `dist:sign` → каждый релизный билд получает новую
монотонно растущую версию, что требуется и electron-updater (обновление только на
более высокую версию), и для различимости инсталляторов.

## R04 — сборка

`npm run dist` → 0.1.0 → 0.1.1, инсталлятор `release/Remote Hub Setup 0.1.1.exe`
(подписан), пакет проверен смоуками.

## Проверка

Правила протестированы на временной копии: patch/minor/major корректно увеличивают
версию, pre-release (`1.0.0-beta`) и мусор (`abc`) отклоняются. Собранный пакет:
`"version": "0.1.1"` в asar, смоук иконок зелёный.
