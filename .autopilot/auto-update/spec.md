# Спецификация

Ядро автообновления уже было в исходной сборке (Updater, IPC, UpdateBar,
пункт меню «Проверить обновления»); этот полёт закрывает пробелы:
видимую ручную проверку, release notes в уведомлении и проверку всего потока.

## R01 — проверка при старте

`Updater.start()` (было): через 8 с после запуска и далее каждые 4 часа.
Только в установленной сборке (`app.isPackaged`), в dev — отключено с
сообщением в лог. Проверено в собранном приложении.

## R02 — ручная проверка

- Меню «Помощь → Проверить обновления» (было): `updater.check(true)` —
  в dev показывает диалог «автообновление недоступно», в установленной —
  «обновлений нет» / «не удалось проверить».
- Новое: в «О программе» появилась секция «Обновления» с живым статусом
  (проверка / доступна версия + release notes / скачивание % / готова к
  установке / ошибка / последняя версия) и кнопкой «Проверить обновления»
  (idle / not-available / error). Кнопка вызывает `checkUpdates` из стора
  (тот же путь IPC, что и меню).

## R03 — уведомление с release notes

- Баннер `UpdateBar` при `available` показывает «Доступна версия N» + кнопку
  «Скачать»; добавлен переключатель **«Что нового»** — раскрывает release
  notes (приходят из GitHub Releases, форматируются в `formatNotes`).
- В «О программе» release notes показываются под строкой о доступной версии.

## R04 — скачивание и установка

Было: `autoDownload = true` + кнопки в баннере «Скачать» / «Перезапустить
и установить» (в `downloaded`), «Позже» (скрыть). В «О программе» те же
действия: «Скачать» (available) и «Перезапустить и установить» (downloaded).

## R05 — проверка

Новый смоук `RH_SMOKE_UPDATE` гоняет все состояния стора: `checking`
(спиннер), `available` (версия + переключатель notes раскрывается, текст
notes виден, кнопка «Скачать»), `downloading` (42% + прогресс-бар),
`downloaded` (кнопка «Перезапустить»), `error` (кнопка «Повторить» вызывает
`checkUpdates` — проверено подменой функции стора), `not-available`/`idle`
(баннер скрыт); затем открывает «О программе» и проверяет секцию
«Обновления» и кнопку «Проверить обновления». Пройден в dev и в собранном
приложении. Версия поднята до 0.1.3, CHANGELOG.md дополнен.
