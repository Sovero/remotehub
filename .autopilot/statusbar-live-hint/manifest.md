# Манифест

| ID | Требование | Статус |
|---|---|---|
| R01 | Для активной VNC-вкладки статусбар показывает локальный порт VNC-моста | in-spec |
| R02 | Для активной RDP-вкладки статусбар показывает адрес RDP-сервера | in-spec |
| R03 | Подсказка живая: исчезает, когда вкладка закрыта или неактуальна | in-spec |
| A01 | Подсказка — иконка из единого набора (link для моста, host для сервера) + тултип | in-spec |
