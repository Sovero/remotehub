# Спецификация

## R01–R03 — живая подсказка активной вкладки

`StatusBar` считает `liveHint` из активной вкладки:

- **VNC** — если у вкладки есть живой мост (`active.vnc?.port`), показывается
  `порт <N>` с иконкой `link` и тултипом «Локальный порт VNC-моста».
- **RDP** — адрес сервера из узла дерева (`findNode(tree, hostId)`) или из
  ad-hoc хоста; при нестандартном порте (≠3389) добавляется `:port`; иконка `host`,
  тултип «Адрес RDP-сервера».
- Подсказка выводится только для активной вкладки и исчезает при её закрытии
  (поля `vnc`/вкладка пропадают из состояния).

## Проверка

- VNC-смоук (`RH_SMOKE_VNC`): после отрисовки реального кадра проверяет статусбар —
  `порт <N>` с svg-иконкой (`hint=` в выводе).
- Смоук иконок (`RH_SMOKE_ICONS`): через `__RH_STORE__` инжектит RDP-вкладку
  (hostId h2 из сида → 127.0.0.1), проверяет точный текст `127.0.0.1` + иконку,
  затем восстанавливает состояние и убеждается, что подсказка исчезла (`rdp-hint=1`).
