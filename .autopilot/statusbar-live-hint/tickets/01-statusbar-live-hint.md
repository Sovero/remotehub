# T01 — живая подсказка активной вкладки

Требования: R01, R02, R03, A01

## Что сделано

- `StatusBar.tsx`: `liveHint` — для VNC порт моста (`active.vnc?.port`, иконка `link`),
  для RDP адрес сервера из дерева/ad-hoc (иконка `host`, `:port` при ≠3389).
- `index.ts`: VNC-смоук проверяет подсказку после отрисовки кадра; смоук иконок
  проверяет RDP-подсказку через инъекцию вкладки в стор и её исчезновение.
