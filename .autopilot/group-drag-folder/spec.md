# Спека: анимация папки группы при перетаскивании хоста

## Контекст

`GroupRow` в `TreeView` уже отслеживает `dragOver` через `useDragHandlers` (подсветка строки `.tree-row--drop`). Полёт добавляет третье состояние папки группы — «приоткрытая» — и анимацию на время drag-over.

## Требования

### R01 — подсветка
- Строка группы при drag-over: фон `color-mix(in srgb, var(--accent) 12%, transparent)` + акцентная рамка (существующий `.tree-row--drop`).
- Папка группы при drag-over окрашивается акцентным цветом (`.tree-folder--drag { color: var(--accent) }`), с плавным переходом (transition color 0.15s).

### R02/R03 — «приоткрытая» папка + анимация
- `ProtocolIcon` группы получает проп `drag?: boolean` (приоритетнее `open`).
- При `drag` рисуется «приоткрытая» папка: крышка приподнята наполовину (короткая линия с подъёмом) + лоток виден (2 path). Визуально отличается и от закрытой (сплошной контур), и от открытой (крышка поднята выше, лоток ниже).
- Анимация: `.tree-folder--drag svg { animation: folder-ajar 0.9s ease-in-out infinite }` — масштаб 1 → 1.18 с лёгким наклоном -6° (папка «подхватывается»).

### R04 — возврат
- `dragleave`/`drop` снимают `dragOver`: класс `tree-folder--drag` исчезает, иконка возвращается к состоянию развёрнутости группы, цвет — к `var(--warn)`.

### A02 — проверка
- Смоук `RH_SMOKE_ICONS`: синтетический `dragover` на группе → `.tree-folder--drag` появляется, папка из 2 path (приоткрыта); `dragleave` → класс исчезает (не залипает). Результат: `…:drag=1`.

## Проверка
- `RH_SMOKE_ICONS` (включая `drag=1`) и `RH_SMOKE_CONTRAST` зелёные в dev и packaged.
- 107/107 тестов, typecheck обоих проектов чист.
