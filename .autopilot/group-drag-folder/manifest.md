# Манифест: анимация папки группы при перетаскивании хоста

| ID | Требование | Статус |
|----|-----------|--------|
| R01 | Во время drag-over группа подсвечивается | in-spec |
| R02 | Папка группы во время drag-over «приоткрыта» (третье состояние иконки) | in-spec |
| R03 | Приоткрытие анимировано (пульсация папки) | in-spec |
| R04 | После ухода мыши папка возвращается в исходное состояние | in-spec |
| A01 | Приоритет состояния drag над состоянием развёрнутости: drag-папка видна даже у развёрнутой группы | in-spec |
| A02 | Смоук проверяет появление/исчезновение подсветки и смену иконки при dragover/dragleave | in-spec |
