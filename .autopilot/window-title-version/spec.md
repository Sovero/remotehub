# Спецификация

## R01 — версия в заголовке окна

`createWindow` в main задаёт `title: Remote Hub v${app.getVersion()}`.
В dev `app.getVersion()` возвращает версию Electron (например 43.4.0),
в установленной сборке — версию приложения (0.1.3) из package.json.
Версия и так была в статусбаре и в «О программе»; заголовок окна
дополняет их — видна всегда, без открытия настроек.

## R02 — защита от перезаписи HTML-тегом

Заголовок страницы (`<title>Remote Hub</title>` в index.html) по умолчанию
перезаписывает заголовок окна после загрузки. Добавлен обработчик
`page-title-updated` с `preventDefault()` — версионированный заголовок
остаётся постоянным.

## R03 — проверка

Базовый смоук (RH_SMOKE=1, выполняется во всех смоуках) после монтирования
React проверяет `mainWindow.getTitle()` по шаблону
`/^Remote Hub v\d+\.\d+\.\d+$/`. Пройдено в dev (v43.4.0 — версия Electron)
и в собранном приложении (v0.1.3). Установщик пересобран, остальные смоуки
(update, icons) зелёные.
