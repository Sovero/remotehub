# Спецификация

## R01 — кликабельная версия

Версия в правой части статусбара — кнопка `.statusbar-version` (иконка окна + текст).
Клик открывает диалог «О программе»; у кнопки тултип, hover-подсветка и
акцентная focus-рамка (доступность с клавиатуры).

## R02 — версия, Electron, архитектура

Диалог показывает имя и логотип приложения (иконка `window` на акцентном фоне),
`v<версия> · Electron <версия> · <архитектура>` — данные из уже существующего
`appInfo` (main → renderer), без новых запросов.

## R03 — changelog последнего релиза

- `CHANGELOG.md` в корне проекта (формат Keep a Changelog).
- `src/shared/changelog.ts` — чистый парсер (`parseChangelog`, `findChangelogEntry`)
  без зависимостей от Electron, покрыт юнит-тестами.
- Новый IPC `app:changelog`: main читает файл и возвращает записи; путь
  вычисляется от `__dirname` (`out/main` → `../../CHANGELOG.md`), что работает
  в dev, в смоуке и внутри asar (файл добавлен в `files` electron-builder).
- Диалог показывает запись для текущей версии приложения; если такой нет —
  самую свежую (первую) запись. Секции (Добавлено/Исправлено/…) — подзаголовками,
  пункты — списком; при ошибке чтения — понятное сообщение, при пустом
  changelog — «Список изменений пока пуст».

## R04 — changelog в релизной сборке

`CHANGELOG.md` добавлен в `files` electron-builder; проверено, что файл лежит
внутри `app.asar` в собранном приложении.

## R05 — проверка

- Юнит-тесты парсера: разбор версий/дат/секций, порядок, CRLF, пустой файл,
  поиск записи по версии и fallback на самую свежую.
- Смоук иконок дополнен проверкой «О программе»: клик по версии открывает
  диалог, в нём есть версия (regex `v\d+\.\d+\.\d+`), заголовок «Что нового»,
  блок «Версия …» и пункты списка; Esc закрывает.
- Смоук контраста не затронут (кнопка версии — тот же `.statusbar-item`).
- Пройдено в dev и в собранном приложении (включая чтение changelog из asar).
