# Спека: иконки состояний (спиннеры загрузки)

## Контекст

После добавления набора иконок (`.autopilot/ui-icons/`) кнопки имеют статичные иконки. Этот полёт добавляет иконки *состояния* — вращающиеся индикаторы занятости — на все длительные операции: проверка доступности, подключение вкладок, загрузка SFTP-каталогов.

## Единый механизм

- В `Icon.tsx` добавлена иконка `spinner` — дуга окружности (stroke = currentColor, рисуется цветом текста как остальные иконки).
- В `global.css` — класс `.icon-spin` с анимацией `icon-spin` (линейное вращение 360° за 0.8s). Любая иконка набора получает вращение добавлением класса.
- Механизм один для всех мест: «иконка состояния» = `<Icon name="spinner" className="icon-spin" />`.

## Требования

### R01 — спиннер на кнопке проверки доступности
- Кнопка «Проверить доступность всех хостов» (заголовок «Профили»): в покое — иконка `refresh`; во время массовой проверки — вращающийся `spinner` (`icon-spin`).
- Клик во время проверки по-прежнему **останавливает** проверку (подсказка кнопки остаётся «Остановить проверку доступности»); после остановки кнопка возвращается к `refresh`.
- Одиночная проверка (контекстное меню → «Проверить доступность»): в тултипе строки TCP/ping уже имеют CSS-спиннер — оставлен как есть.

### R02 — анимированная иконка загрузки в SFTP
- Панель «Подключение SFTP…» (пока соединение не установлено): статичная «⇅» заменена на вращающийся `spinner` (44px).
- Колонка каталога в состоянии загрузки («Загрузка…»): вращающийся `spinner` (13px) рядом с текстом.

### R03 — анимированная иконка загрузки во вкладках
- Вкладка в состоянии `connecting`: вместо пульсирующей точки — вращающийся `spinner` (10px). Остальные состояния (ok/error/warn) — цветные точки как раньше; подсказка вкладки не меняется.

### R03.1 — запуск Remote Desktop
- Панель «Запуск Remote Desktop…»: статичная «▤» заменена на вращающийся `spinner` (44px). (Пустая область вкладки `EmptyWorkspace` и `PlaceholderPane` «не реализован» — это не загрузка, остаются статичными.)

### A01 — остановка массовой проверки
- Поведение клика сохранено: вращающийся спиннер не отменяет возможность остановить проверку; подсказка и действие кнопки в состоянии проверки — «Остановить проверку доступности».

### A02 — проверка обновлений
- Баннер «Проверка обновлений…»: вращающийся `spinner` (12px) перед текстом — тот же паттерн иконок состояния.

## Проверка

- Смоук `RH_SMOKE_ICONS` расширен: клик по кнопке массовой проверки → в течение ≤4 с в кнопке появляется `svg.icon-spin` → повторный клик останавливает и возвращает `refresh`. Проверяется и в dev, и в packaged-сборке.
- Тесты: 107/107 (изменений логики нет — только рендер), typecheck обоих проектов чист.
