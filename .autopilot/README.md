# Как читать эту папку

- `dashboard.html` — открой двойным кликом. Прогресс, график, что осталось.
- `remote-hub/brief.md` — твоя изначальная задача, слово в слово. Не редактируется.
- `remote-hub/manifest.md` — список требований и что с каждым стало.
- `remote-hub/spec.md` — техзадание.
- `remote-hub/tickets/` — задачи, на которые разбита сборка.

Если сборка прервалась — скажи агенту «продолжи автопилот», он поднимет состояние отсюда.
