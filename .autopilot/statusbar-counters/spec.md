# Спецификация

## R01–R03 — индикатор «хосты / сессии»

Слева в строке статуса — группа `.statusbar-counters`:

- иконка `tree` (дерево профилей: ствол + три ветви) и число — всего хостов в дереве (`flattenHosts(tree).length`);
- вертикальный разделитель `.statusbar-divider`;
- иконка `tab` (вкладка с головой-выступом) и число — активных сессий (фазы `connecting`, `connected`, `auth-required`).

Обе иконки добавлены в единый набор `Icon.tsx` (stroke, `currentColor`). Числа — `tabular-nums`,
тултип раскрывает смысл («Хостов: N · Активных сессий: M»).

## Проверка

Смоук иконок проверяет счётчики: две svg-иконки ненулевого размера, разделитель на месте,
значения 3 хоста / 0 сессий на сид-профилях (`counters=1`). Смоук контраста сканирует
`.statusbar-item` (включая новые счётчики) во всех 12 комбинациях тем × акцентов.
