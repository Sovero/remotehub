# Бриф: понятные сообщения об ошибках в VNC-вкладке

> «Добавить понятные сообщения об ошибках в VNC-вкладку для случаев, когда сервер не отвечает на рукопожатие или требует не поддерживаемый тип шифрования»

Пользователь просит, чтобы VNC-вкладка объясняла две типичные поломки подключения
внятным текстом: сервер молчит (не отвечает на рукопожатие) и сервер требует
тип шифрования, который приложение не поддерживает.
