# Спецификация

## R01 — заставка окна

Пока `ready === false` вместо текста «Загрузка…» показывается экран
`LoadingSplash`: логотип-иконка на акцентном фоне, «Remote Hub»,
**«Версия X.Y.Z»** и анимированные точки «Загрузка…». Версия берётся
из `window.api.appInfo()` напрямую (самодостаточная заставка — не зависит
от порядка инициализации стора). Данные уже есть в сторе (`appInfo`),
запрос дополнительный только если они ещё не загружены.

## R02 — мастер-онбординг

В футер тултипа тура (`InteractiveTour`) добавлен элемент
`.tour-tooltip-version` — «vX.Y.Z» из `appInfo` стора (тур открывается
только после `ready`, поэтому версия гарантированно загружена). Виден
на каждом шаге тура, включая первый запуск.

## R03 — проверка

Смоук иконок дополнен (`ui-version=1`):
- заставка: `store.setState({ ready: false })` → `.loading-version` совпадает
  с шаблоном `Версия X.Y.Z` → `ready: true`;
- онбординг: `openOnboarding()` → в `.tour-tooltip-version` шаблон `vX.Y.Z`
  → `closeOnboarding()` не оставляет оверлей.
Пройдено в dev и в собранном приложении. Версия поднята до 0.1.4,
CHANGELOG.md дополнен.
