# 01 — Встраивание RDP в main: движок, менеджер, IPC

**Требования:** R01, R01.1, R01.2, R01.3, R02i
**Blocked by:** —
**Status:** ready

## Что должно заработать

Главный процесс умеет встраивать окно нативного mstsc в окно приложения: найти окно по PID,
установить родителем HWND окна Electron, снять заголовок/рамку, позиционировать в прямоугольник
панели (физические пиксели), скрывать/показывать, закрывать. Профили с полным экраном или
мультимонитором не встраиваются (фолбэк в отдельное окно). Все исходы приходят в рендерер.

## Из брифа, дословно

> «rdp-подключение открывается в отдельном окне, а должно открываться внутри приложения — исправь»

## Критерии приёмки

- [ ] Зависимость `koffi` добавлена в `dependencies` и в `asarUnpack` electron-builder; движок
      загружает её лениво и только на Windows (на других платформах/в тестах — не падает)
- [ ] `RdpEmbedEngine` (интерфейс + koffi-реализация + фейк для тестов): EnumWindows по PID,
      SetParent, снятие WS_CAPTION/WS_THICKFRAME/WS_EX_APPWINDOW, SetWindowPos, ShowWindow
      SW_HIDE/SW_SHOW, PostMessage WM_CLOSE, IsWindow, SetForegroundWindow
- [ ] `RdpManager.launch`: при `screenMode:'window'` и `multiMonitor:false` — embed-путь; при
      полном экране/мультимониторе — фолбэк в отдельное окно; результат содержит
      `mode: 'embedded' | 'window'`
- [ ] Окно ищется до ~15 с; не найдено → процесс mstsc убивается, рендереру уходит
      `rdp:exited` с понятной ошибкой
- [ ] `stop(sessionId)` закрывает встроенное окно (WM_CLOSE) и дожидается выхода процесса;
      `closeAll()` (выход приложения) закрывает всё и убивает зависшие процессы
- [ ] Сторож раз в ~2 с перепроверяет IsWindow и перевстраивает пересозданное окно; re-assert
      геометрии по последнему rect
- [ ] IPC-каналы `rdp:rect`, `rdp:activate`, `rdp:overlay` добавлены в контракт и обработаны;
      CSS-прямоугольник переводится в физические пиксели по scaleFactor дисплея
- [ ] Юнит-тесты на фейке: появление окна после N опросов, embed с верными аргументами,
      реект, stop/closeAll, фолбэк; полный прогон `npm test` зелёный
- [ ] `RH_SMOKE_RDP_EMBED=1`: main сам запускает реальный mstsc на мёртвый порт, ждёт факта
      встраивания (HWND найден и встроен), закрывает сессию, exit 0
