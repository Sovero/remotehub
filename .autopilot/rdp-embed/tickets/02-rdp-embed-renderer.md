# 02 — Рендерер: встроенная панель RDP, тексты, смоук

**Требования:** R01, R01.1, R01.3, R03i, R04i, A01
**Blocked by:** 01
**Status:** ready

## Что должно заработать

Вкладка RDP показывает подложку, поверх которой main встраивает живое окно mstsc: рендерер
измеряет панель вкладки и шлёт её прямоугольник, активирует/прячет окно при переключении вкладок,
прячет при открытии модальных диалогов, честно показывает фолбэк для полного экрана и ошибки.
Справка, онбординг и FAQ описывают встраивание.

## Из брифа, дословно

> «rdp-подключение открывается в отдельном окне, а должно открываться внутри приложения — исправь»

Истории 1–10; Решения §4, §6, §7; Швы §3–§4.

## Критерии приёмки

- [ ] В preload добавлены `rdpSetRect(sessionId, rect)`, `rdpActivate(sessionId)`,
      `rdpOverlay(active)` (файр-энд-форгет, через `ipcRenderer.send`)
- [ ] `RdpPane`: при `phase==='connected'` и `mode==='embedded'` — подложка с замером
      `getBoundingClientRect` (ResizeObserver + window resize, троттлинг); rect шлётся только для
      активной вкладки; при `mode==='window'` — честный статус «полный экран не встраивается»
- [ ] `switchTab` шлёт `rdpActivate` (для RDP-вкладок); `openDialog`/`closeDialog` шлют
      `rdpOverlay(true/false)` (плюс онбординг)
- [ ] Тексты: панель RDP, справка (RDP-раздел + FAQ «открывается в отдельном окне?»), онбординг —
      больше не утверждают «отдельное окно»; описывают встраивание и исключение для полного экрана
- [ ] `RH_SMOKE_RDP=1` (fake-режим) проходит: вкладка connected → closed; в fake-режиме
      `rdp:rect`/`rdpActivate` не роняют рендерер
- [ ] `npm run typecheck` чист
