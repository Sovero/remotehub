# Манифест требований

Источник: `brief.md`. Строку из этого списка может снять **только пользователь**.

| ID | Из брифа (дословно) | Статус | Основание | Где |
|----|---------------------|--------|-----------|-----|
| R01 | «rdp-подключение открывается в отдельном окне, а должно открываться внутри приложения» | in-ticket | ASSUMPTION — принято за пользователя: встраиваем нативное окно mstsc как дочернее HWND окна Electron (SetParent); это единственный способ сохранить нативный RDP-клиент (NLA, TLS, буфер обмена) без внешних серверов/шлюзов | spec §3 → T01, T02 |
| R01.1 | *(подразумевается)* встроенная сессия живёт в рабочей области вкладки и следует за её размером | in-ticket | ASSUMPTION — принято за пользователя: панель вкладки = область встраивания; ресайз окна/вкладки перекладывает окно mstsc следом | spec §3.2 → T01, T02 |
| R01.2 | *(подразумевается)* полноэкранный/мультимониторный RDP | in-ticket | ASSUMPTION — принято за пользователя: профили RDP с полным экраном или мультимонитором физически нельзя встроить (RDP требует fullscreen) → остаются отдельным окном, приложение сообщает об этом; остальные встраиваются | spec §3.6 → T01 |
| R01.3 | *(подразумевается)* закрытие вкладки/приложения завершает сессию | in-ticket | ASSUMPTION — принято за пользователя: встроенная сессия живёт, пока открыта вкладка; закрытие вкладки или приложения закрывает окно mstsc (раньше «оставалось жить после выхода» — это следствие встраивания) | spec §3.5 → T01, T02 |
| R02i | *(подразумевается)* сбой запуска/потеря окна видны в вкладке | in-ticket | ASSUMPTION — принято за пользователя: все исходы (не найдено окно, mstsc упал, сессия завершена) приходят в оверлей вкладки, как у SSH/VNC | spec §3.5 → T01 |
| R03i | *(подразумевается)* справка/онбординг/FAQ честно описывают поведение | in-ticket | ASSUMPTION — принято за пользователя: тексты «открывается в окне mstsc» заменяются на «встроено во вкладку»; фолбэк для fullscreen описан | spec §4 → T02 |
| R04i | *(подразумевается)* управление вкладкой (перезапуск, закрытие, переключение) работает как у других протоколов | in-ticket | ASSUMPTION — принято за пользователя: переключение вкладок показывает/прячет встроенное окно; перезапуск и закрытие как у VNC/SSH | spec §3.4 → T02 |
| A01 | *(дополнение)* окно mstsc не должно накрывать модальные диалоги приложения | in-ticket | ASSUMPTION — принято за пользователя: при открытии любого диалога/онбординга встроенные окна временно скрываются и возвращаются после закрытия | spec §3.4 → T02 |
