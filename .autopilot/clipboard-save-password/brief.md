# Бриф: буфер обмена из сессии и сохранение пароля SSH

> «1. при подключении к удаленному столу, ssh - нет возможности копировать в буфер с сервера
> 2. Дать возможность сохранить пароль для подключения по ssh»

Пользователь работает в удалённых сессиях (RDP и SSH) и хочет:
копировать текст из сессии в буфер Windows штатным для сервера способом (Ctrl+C в
удалённой программе / OSC 52 в терминале), а пароль SSH — вводить один раз,
сохранив его в профиле хоста.
