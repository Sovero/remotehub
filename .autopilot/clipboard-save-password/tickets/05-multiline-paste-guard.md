# T05 — Защита терминала от многострочной вставки

**Требования:** R06

## Что сделано

- `src/renderer/src/components/TerminalPane.tsx`
  - `requestPaste(text)` — единая точка вставки: `splitPasteLines` даёт ≤ 1 строку →
    `term.paste(toTerminalInput(text))` сразу; больше — открывается диалог.
  - `Modal` «Вставка нескольких строк»: счётчик строк и предпросмотр (первые 5),
    кнопки «Отменить», «Вставить всё» (`pasteEverything`), «Построчно»
    (`pasteNextLine` — по строке за нажатие, в диалоге видна очередная строка).
  - `toTerminalInput` переводит LF → CR: в терминал Enter приходит как CR, и только он
    гарантированно выполняет команду.
  - Все входы вставки идут через `requestPaste`: Ctrl+Shift+V, ПКМ без выделения и
    `registerTermPaste` (сниппеты/меню через `pasteToTerminal`).
