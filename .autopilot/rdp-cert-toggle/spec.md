# Спека: переключатель авто-подтверждения сертификата RDP

## Задача

Авто-подтверждение предупреждения безопасности mstsc (непроверенный сертификат) стало
поведением по умолчанию. Пользователь хочет переключатель: «авто-подтверждать» (как сейчас)
или «показывать предупреждение» — тогда диалог остаётся видимым, и он решает сам.

## Решение

1. **Настройка** `rdpAutoAcceptCert: boolean` (по умолчанию `true`) в `Settings` +
   `DEFAULT_SETTINGS`. Чекбокс в форме настроек («Авто-подтверждать сертификат RDP»)
   с пояснением: «Вкл: предупреждение о недоверенном сертификате гасится автоматически.
   Выкл: оно показывается при каждом подключении — вы решаете сами».
2. **Применение в рантайме**: `settings:set` → `rdp.setAutoAcceptCert(...)` — работает для
   уже открытых сессий (следующий тик сторожа) и новых.
3. **Единая точка принятия решения — менеджер** (`src/main/rdp/manager.ts`):
   - `attachWindow` — подтверждает до поиска окна (чтобы диалог не перекрывал встраивание),
   - `tick` — подтверждает, если диалог всплыл после встраивания,
   - оба вызова под флагом `autoAcceptCert`.
   Движок (`findWindowByPid`) больше не гасит предупреждение внутри себя — иначе настройка
   не управляла бы этим путём. Диалог по-прежнему исключается из кандидатов на встраивание
   (`isSkipWindow`) — встраивается окно сессии, а не диалог.

## Пользовательские истории

| # | Метка | История | Приёмка |
|---|-------|---------|---------|
| 1 | R01 | Как пользователь, я включаю «Авто-подтверждать сертификат RDP» и не вижу предупреждение | смоук против живого RDP-сервера: «окно встроено, предупреждение безопасности погашено» |
| 2 | R01.1 | …а выключаю — предупреждение показывается, и я решаю сам | смоук: «окно встроено, предупреждение показано пользователю (видимых: 1)» |
| 3 | A01 | …и настройка применяется без перезапуска приложения | `setAutoAcceptCert` в тесте: включение после запуска начинает гасить предупреждение |

## Решения по реализации

1. `src/shared/types.ts` — поле `rdpAutoAcceptCert` в `Settings` и `DEFAULT_SETTINGS` (true).
2. `src/renderer/src/components/SettingsForm.tsx` — чекбокс с hint.
3. `src/main/rdp/manager.ts` — флаг + `setAutoAcceptCert()`; confirm в `attachWindow`/`tick`
   только при `autoAcceptCert`.
4. `src/main/rdp/win32-engine.ts` — убран авто-confirm из `findWindowByPid` (решение в менеджере).
5. `src/main/ipc.ts` — `settings:set` пробрасывает значение в менеджер.
6. `src/main/index.ts` — начальное значение менеджеру из хранилища.
7. `tests/rdp-embed.test.ts` — тест «выключенный авто-подтверждение не гасит предупреждение»
   + переключение через `setAutoAcceptCert`.
8. `src/main/index.ts` (смоук) — `RH_SMOKE_RDP_EMBED` с `RH_RDP_AUTO_ACCEPT=0`: ждём, что
   предупреждение ОСТАЛОСЬ видимым (exit 0), иначе — что погашено.

## Вне рамок

| Требование | Почему не сейчас |
|---|---|
| Разрешать сертификат для конкретного хоста (доверять навсегда) | mstsc в новых Windows не запоминает принятый сертификат (проверено ранее) — список доверенных хостов пришлось бы вести самому приложению; не заказано |
| Три состояния: авто / спрашивать / отключить проверку | не заказано; достаточно бинарного переключателя из брифа |
