# Интерфейсы: контраст иконок и видимость кнопок-иконок

## CSS-переменные (устанавливаются в App.tsx)
- `--accent-fg` — цвет текста/иконок поверх акцентного фона: `#ffffff` для тёмных акцентов (яркость ≤ 0.30), `#141519` для светлых.
- `--accent-hover` — hover-фон акцента: тёмные акценты затемняются (`mixWithBlack(0.1)`), светлые осветляются (`mixWithWhite(0.18)`).
- Использовать `var(--accent-fg)` везде, где текст/иконка лежит на акцентном фоне; `var(--accent-hover)` — hover-фон таких поверхностей.

## Хук для смоуков
- `window.__RH_STORE__` (main.tsx) — zustand-хук приложения; смоук вызывает `__RH_STORE__.getState().patchSettings({ theme, accent })`.

## Смоук
- `RH_SMOKE_CONTRAST=1`: открывает панель настроек, диалог хоста и контекстное меню, затем для 2 тем × 6 акцентов измеряет WCAG-контраст иконок/текста против эффективного фона (композиция слоёв) и hover-контраст по `--accent-fg`/`--accent-hover`. Порог 3:1. Результат: `ok:dark:#2d95ec=3.17 …`.
- `RH_SHOT_DIR=<dir> RH_SHOT_THEME=<dark|light> RH_SHOT_ACCENT=<hex>` — сохраняет скриншот окна в `<dir>/<theme>-<accent-hex>.png`.
