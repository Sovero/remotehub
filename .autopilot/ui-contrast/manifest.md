# Манифест: контраст иконок и видимость кнопок-иконок

| ID | Требование | Статус |
|----|-----------|--------|
| R01 | Проверен контраст иконок в светлой теме — слабые места исправлены | in-spec |
| R02 | Проверен контраст иконок при нестандартном акцентном цвете — исправлен | in-spec |
| R03 | Улучшена видимость кнопок-иконок (tabbar, тулбары, контекстное меню, закрытие) | in-spec |
| R04 | Контраст проверяется автоматически: смоук по темам × акцентным цветам (порог 3:1) | in-spec |
| A01 | Цвет текста/иконок поверх акцента (`--accent-fg`) выбирается по яркости: светлые акценты — тёмный текст | in-spec |
| A02 | Hover-фон акцента адаптивный: тёмные акценты затемняются, светлые осветляются — контраст не падает ниже 3:1 | in-spec |
| A03 | Акцентные метки-теги в дереве смешиваются с цветом текста — читаемы при любом акценте | in-spec |
