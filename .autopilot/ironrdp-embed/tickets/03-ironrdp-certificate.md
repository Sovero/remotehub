# 03 — Сертификат: баннер и авто-подтверждение

**Требования:** G02, G02.1, G02.2
**Blocked by:** 02
**Status:** ready

## Что должно заработать

При подключении к серверу с недоверенным TLS-сертификатом IronRDP выбрасывает
событие. Если `rdpAutoAcceptCert=true` — сертификат принимается молча. Если
`false` — во вкладке появляется баннер «Сертификат RDP не доверен» с кнопками
«Подключить» и «Отмена». Системного диалога нет. Решение пользователя
передаётся обратно в IronRDP.

## Из брифа, дословно

> *(из брифинга)* «Да, баннер во вкладке»

## Критерии приёмки

- [ ] IronRDP certificate event → main → IPC → renderer: `rdp:certificate { pending: true }`
- [ ] `rdpAutoAcceptCert=true` → сертификат принимается автоматически, баннера нет
- [ ] `rdpAutoAcceptCert=false` → баннер во вкладке с кнопками Подключить/Отмена
- [ ] Кнопка «Подключить» → `rdpAcceptCertificate` → IronRDP продолжает сессию
- [ ] Кнопка «Отмена» → `rdpRejectCertificate` → вкладка закрывается с сообщением
- [ ] Переключатель в Настройках меняет поведение без перезапуска приложения
- [ ] Существующий `rdp-cert-banner` CSS переиспользован (без дублирования)
