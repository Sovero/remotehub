# 02 — Canvas: рендеринг, ввод, разрешение, immersive

**Требования:** R01, R04, R05, R10i, R05.2, G01, G01.1, G01.2, G01.3
**Blocked by:** 01
**Status:** ready

## Что должно заработать

Внутри RDP-вкладки — canvas с удалённым рабочим столом. Мышь и клавиатура
передаются на сервер, курсор удалённого стола двигается плавно. При ресайзе
вкладки разрешение меняется автоматически (Display Control). Immersive-режим
разворачивает рабочий стол на всё окно приложения (Escape — выход).
Дропдаун разрешения в тулбаре сохраняет выбор в профиль — применяется при
следующем подключении.

## Из брифа, дословно

> «все подключения должны открываться только внутри окна и никак иначе»
> «рабочий стол виден»

## Разделы спеки

Истории 1, 3, 4, 7, 8, 9, 16. Решения: Разрешение, Immersive.

## Критерии приёмки

- [ ] `<iron-remote-desktop>` веб-компонент рендерит canvas с рабочим столом
- [ ] Мышь: клик, движение, скролл передаются на сервер через IPC
- [ ] Клавиатура: набор текста и спецклавиши передаются
- [ ] Системный курсор скрыт, remote cursor рисуется на canvas
- [ ] ResizeObserver → Display Control: при ресайзе окна сервер получает новый размер
- [ ] Immersive: тулбар скрыт, canvas на весь viewport; Escape выходит
- [ ] Дропдаун разрешения сохраняет в профиль без переподключения
- [ ] При дисконнекте canvas очищается (чёрный фон)
