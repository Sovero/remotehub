# Изначальная задача

> Записано 2026-08-24. Этот файл не редактируется — он эталон, с которым
> сверяется готовый результат.

все подключения должны открываться только внутри окна и никак иначе. изучи все программы удаленного подключения и выбери примеры для использования

https://github.com/GoSecure/pyrdp
https://github.com/citronneur/rdpy
https://abi-jey.github.io/simple-rdp/
используй варианты работы с rdp в окне

RDP-подключение должно открываться внутри вкладки приложения: рабочий стол виден,
панель подключения (BBAR) не появляется, внешних окон mstsc нет. Подключение
работает с серверами Windows, требующими NLA (Network Level Authentication).

Текущий подход через mstsc.exe + SetParent даёт: плавающую чёрную панель BBAR,
проблемы с Z-порядком (окно mstsc под слоем Chromium), нестабильную верификацию
встраивания (WS_CHILD vs GetAncestor).

node-rdpjs (2015) не поддерживает NLA/CredSSP — падает на X224_NEG_FAILURE.
Нужна библиотека с полной поддержкой современных RDP-серверов.
