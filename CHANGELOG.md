# Changelog

Все заметные изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование — семантическое (MAJOR.MINOR.PATCH).

## [0.1.4] — 2026-08-23

### Добавлено
- Версия приложения в заставке при запуске (логотип, имя, версия)
  и в тултипах мастера-онбординга.

## [0.1.3] — 2026-08-23

### Добавлено
- Автообновление через electron-updater: проверка при старте и по расписанию,
  ручная проверка из меню и из «О программе», баннер с уведомлением о новой
  версии и release notes.
- Версия в заголовке окна приложения (Remote Hub vX.Y.Z) — видна всегда,
  без открытия настроек.

## [0.1.2] — 2026-08-23

### Добавлено
- Версия в строке статуса стала кликабельной: диалог «О программе»
  с версией приложения и списком изменений последнего релиза.

## [0.1.1] — 2026-08-23

### Добавлено
- Правила версионирования билдов: каждый релизный билд (`dist` / `dist:sign`)
  автоматически получает новую монотонно растущую semver-версию
  (`scripts/bump-version.mjs`, патч по умолчанию, `--minor` / `--major`).
- Живая подсказка активной вкладки в строке статуса: локальный порт VNC-моста
  или адрес RDP-сервера.
- Индикатор «хостов / активных сессий» в строке статуса с иконками дерева и вкладок.
- SVG-иконки в моках встроенной справки вместо текстовых глифов.
- Иконки в строке статуса и пустых состояниях (Welcome, EmptyWorkspace).

### Исправлено
- Контраст иконок: читаемость во всех темах и при любом акцентном цвете
  (автоматический выбор цвета текста поверх акцента, адаптивный hover).
- Зелёный цвет «Готово» в светлой теме затемнён до читаемого.

## [0.1.0] — 2026-08-22

### Добавлено
- SSH, Telnet, RDP, VNC и SFTP сессии.
- RDP открывается внутри приложения (встроенное окно mstsc), с выбором
  «окно / полный экран» прямо из вкладки.
- VNC открывается внутри приложения через локальный мост.
- Переключатель авто-подтверждения сертификата RDP (показывать предупреждение
  для недоверенных хостов или подтверждать автоматически).
- Понятные сообщения об ошибках VNC: сервер молчит / не-RFB / неподдерживаемое
  шифрование.
- Иконки для кнопок, спиннеры загрузки (проверка доступности, SFTP, вкладки).
- Иконки узлов дерева профилей: группы (папки), шевроны, протокольные иконки.
- Анимация папки группы при перетаскивании хоста: подсветка и «приоткрытая» папка.
- SFTP: иконки файлов/папок, направления передач, галочки завершения.
