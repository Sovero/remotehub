# Changelog

Все заметные изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование — семантическое (MAJOR.MINOR.PATCH).

## [0.1.12] — 2026-08-26

### Исправлено
- IronRDP: мост не мог получить сертификат RDP-хоста, потому что пробное
  TLS-соединение не начинало рукопожатие (`tls.TLSSocket` поверх
  существующего сокета не шлёт ClientHello). Из-за этого клиенту уходила
  пустая цепочка сертификатов, WASM-клиент IronRDP обрывал соединение
  сразу после X.224 («server cert chain missing»), и окно удалённого ПК
  не появлялось. Проба теперь использует `tls.connect({ socket })` —
  цепочка сертификатов доходит до клиента, соединение держится.

## [0.1.11] — 2026-08-26

### Исправлено
- Подключение RDP к современным Windows-хостам: по умолчанию используется
  движок IronRDP (WASM) с поддержкой NLA/CredSSP вместо устаревшего
  node-rdpjs, который не умеет NLA и из-за этого не мог подключиться
  к хостам с включённой сетевой аутентификацией (соединение закрывалось
  сразу после рукопожатия). Движок по-прежнему можно переключить
  в настройках (⚙ → Движок RDP).

### Изменено
- Настройки открываются модальным окном по центру, как остальные диалоги,
  а не выезжающей панелью в левой колонке.
- Кнопки внизу панели профилей выровнены в сетку одинаковой ширины;
  «Группа» и «Хост» выделены акцентным цветом.
- Убраны кнопки фонового мониторинга из шапки панели профилей; доступность
  отдельного хоста проверяется правым кликом → «Проверить доступность».

### Добавлено
- Opt-in E2E-тест живого RDP-хоста через IronGateway (`npm run test:e2e:rdp`):
  проверяет TCP-подключение и X.224-переговоры без логина и пароля.

## [0.1.10] — 2026-08-25

### Исправлено
- Рабочий стол RDP-сессии снова виден во вкладке: COM-хост отдаёт наружу
  HWND окна-контейнера, а не дочернего HWND ActiveX-контрола. После SetParent
  в окно Electron контрол сохраняет своего OLE-родителя и продолжает получать
  WM_SIZE, сообщения и отрисовку; WM_SIZE контейнера масштабирует контрол.
- `scripts/build-com-host.cmd` — воспроизводимая пересборка rdp-com-host.exe
  (vswhere → vcvars64 → cl); exe пересобран из текущего исходника.
- Приложение надёжно показывает главное окно при запуске: сохранённые
  координаты окна возвращаются в видимую область экрана, путь к иконке
  различает dev-режим и упакованную сборку, ошибки инициализации пишутся
  в диагностический лог.
- Версия Electron убрана из интерфейса: строка статуса, «О программе»,
  встроенная справка и нативный диалог меню больше не показывают версию
  Electron; архитектура (`x64`) сохранена.

## [0.1.8] — 2026-08-24

### Добавлено
- RDP-подключения используют C++ COM-хост (rdp-com-host.exe, 300 KB) вместо
  mstsc.exe: MsTscAx ActiveX загружается in-process в скрытое окно, HWND
  передаётся в Electron через stdout для SetParent. Ноль mstsc.exe в
  процессах.
- Resize-команда в stdin COM-хоста с debounce 300 мс: при изменении размера
  вкладки RDP-сессия адаптирует разрешение удалённого рабочего стола.

### Исправлено
- CLSID MsTscAx.MsTscAx.10 ({8B918B82-...}) вместо незарегистрированного
  MsRdpClient9: COM-хост создаёт HWND без ошибки 0x80040154.
- DISPID ищутся через GetIDsOfNames вместо хардкода — Connect, Server,
  UserName, SecuredSettings2 работают на любой версии Windows.
- Пароль через cmdkey-инъекцию: ClearTextPassword через IDispatch
  возвращает E_ACCESSDENIED, обход — Credential Manager.
- Баннер «ENOENT app-update.yml» подавлен в unpacked-сборках.
- JS-зависимости bundle внутрь out/main/index.js вместо require():
  electron-updater, ssh2, ws и др. больше не теряются в asar.
- Stale lockfile старше 30 секунд удаляется перед повторным захватом.

## [0.1.7] — 2026-08-23

### Исправлено
- 64-битные HWND больше не обрезаются до Number: весь поток указателей окон
  (getNativeWindowHandle → SetParent) переведён на bigint. Это убирает ошибку
  «SetParent не привязал окно mstsc к окну приложения» при встраивании RDP.
- Packaged-приложение падало при старте: koffi-тип BOOL не был определён при
  загрузке из asar (добавлен явный alias). Electron-builder скачивал другой
  бинарник Electron 43.4.0 — закреплён electronDist на локальной версии.

## [0.1.6] — 2026-08-23

### Исправлено
- Все remote-сессии остаются внутри главного окна: RDP fullscreen и multi-monitor
  проходят через единый embedded-путь без `mode=window` и внешнего fallback.
- Системное предупреждение сертификата RDP скрывается у `mstsc` и переносится
  в баннер вкладки при отключённом авто-подтверждении.
- Внешние popup-окна и навигация из renderer блокируются.

## [0.1.5] — 2026-08-23

## [0.1.1] — 2026-08-23

### Добавлено
- Правила версионирования билдов: каждый релизный билд (`dist` / `dist:sign`)
  автоматически получает новую монотонно растущую semver-версию
  (`scripts/bump-version.mjs`, патч по умолчанию, `--minor` / `--major`).
- Живая подсказка активной вкладки в строке статуса: локальный порт VNC-моста
  или адрес RDP-сервера.
- Индикатор «хостов / активных сессий» в строке статуса с иконками дерева и вкладок.
- SVG-иконки в моках встроенной справки вместо текстовых глифов.
- Иконки в строке статуса и пустых состояниях (Welcome, EmptyWorkspace).

### Исправлено
- Контраст иконок: читаемость во всех темах и при любом акцентном цвете
  (автоматический выбор цвета текста поверх акцента, адаптивный hover).
- Зелёный цвет «Готово» в светлой теме затемнён до читаемого.

## [0.1.0] — 2026-08-22

### Добавлено
- SSH, Telnet, RDP, VNC и SFTP сессии.
- RDP открывается внутри приложения (встроенное окно mstsc), с выбором
  «окно / полный экран» прямо из вкладки.
- VNC открывается внутри приложения через локальный мост.
- Переключатель авто-подтверждения сертификата RDP (показывать предупреждение
  для недоверенных хостов или подтверждать автоматически).
- Понятные сообщения об ошибках VNC: сервер молчит / не-RFB / неподдерживаемое
  шифрование.
- Иконки для кнопок, спиннеры загрузки (проверка доступности, SFTP, вкладки).
- Иконки узлов дерева профилей: группы (папки), шевроны, протокольные иконки.
- Анимация папки группы при перетаскивании хоста: подсветка и «приоткрытая» папка.
- SFTP: иконки файлов/папок, направления передач, галочки завершения.
